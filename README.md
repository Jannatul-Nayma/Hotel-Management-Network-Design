# 📖 Overview

This project presents the design and implementation of a hotel enterprise network using Cisco Packet Tracer. The network connects three floors of a modern hotel, providing communication among different departments through VLAN segmentation, dynamic routing, wireless networking, and secure remote administration.

The project demonstrates practical implementation of enterprise networking concepts including OSPF routing, DHCP, SSH, VLANs, and switch port security.

---

# ✨ Features

- 🏨 Three-floor hotel network design
- 🖧 VLAN-based department segmentation
- 🔄 OSPF dynamic routing
- 📡 Wi-Fi connectivity on every floor
- 🌐 Dynamic IP assignment using DHCP
- 🔐 Secure SSH remote login
- 🛡️ Switch port security using Sticky MAC
- 🖨️ Printer connectivity for every department
- 💻 End-to-end communication between all devices

---

# 🏢 Network Layout

The hotel consists of three floors.

### First Floor

- Reception
- Store
- Logistics

### Second Floor

- Finance
- HR
- Sales

### Third Floor

- Administration
- IT Department

Each floor contains:

- One Switch
- Wireless Network
- Department Printers
